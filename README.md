# SUBTEN Website

Official corporate website for SUBTEN Advanced Defense Technologies.

The current release is a cinematic, motion-led single-page experience focused on critical infrastructure protection, integrated sensing, command and control, and sovereign capability building.

## SHMAQ Studio portfolio (`/shmagh`)

A standalone creative-studio portfolio for SHMAQ / Shmagh, built from the company profile (EN/AR).
Pure HTML/CSS/JS — no frameworks — with bilingual EN/AR (RTL) support, case-study overlays,
on-demand Vimeo embeds and responsive WebP images.

Preview locally: `cd shmagh && python3 -m http.server 8080`.
Before launch, replace the placeholder email `hello@shmaq.studio` in `shmagh/index.html`.
